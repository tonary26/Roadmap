<a id="section-1"></a>
## 1. 🎨 Фундамент: HTML/CSS

Основа основ. Без этого не имеет смысла двигаться дальше.

- Семантическая верстка (`header`, `main`, `section`, `footer`)
- Flexbox и CSS Grid - верстка макетов
- Адаптивная верстка (media queries, mobile-first)
- CSS-препроцессоры: **SASS/SCSS**
- Основы **Tailwind CSS** (часто требуется на фрилансе)
- Базовый **JavaScript** (DOM, события)

**Практика:** сверстать 3-5 лендингов по готовым макетам (Figma) без фреймворков.

---

<a id="section-2"></a>
## 2. 🐘 PHP - основы бэкенда

- Синтаксис, типы данных, массивы, функции
- ООП в PHP (классы, интерфейсы, трейты, namespaces)
- Работа с формами, сессии, куки
- Работа с базами данных: MySQL / PostgreSQL, PDO
- Composer
- Паттерны проектирования (MVC, Singleton)
- REST API на чистом PHP (для понимания того что происходит под капотом фреймворков)

**Практика:** написать простую CRUD-систему (например, блог или инет магазин) без фреймворка.

---

<a id="section-3"></a>
## 3. 🅻 Laravel - фреймворк для PHP

- Установка, структура проекта, `artisan`
- Роутинг, контроллеры, middleware
- Eloquent ORM: модели, миграции, связи (hasMany, belongsTo и т.д.)
- Blade-шаблонизатор
- Валидация, Form Requests
- Аутентификация: Laravel Breeze / Jetstream / Sanctum
- API-разработка (REST, ресурсы `API Resources`)
- Очереди (Queues) и Jobs
- События и слушатели (Events & Listeners)
- Laravel + Redis (кэш, очереди, сессии)
- Laravel AI SDK (для внедрения нейронок в проекты)

**Практика:** реализовать полноценный интернет-магазин или CRM с админкой и API.

---

<a id="section-4"></a>
## 4. 💚 VueJS - фронтенд с реактивностью

- Vite - сборка проекта
- Основы Vue 3: реактивность, Composition API
- Компоненты, props, emits, slots
- Vue Router - маршрутизация SPA
- Pinia - управление состоянием (state management)
- Работа с API (axios/fetch), обработка ошибок
- Связка **Laravel + Vue** (SPA или Inertia.js)

**Практика:** превратить лендинг в SPA, подключить к Laravel API.

---

<a id="section-5"></a>
## 5. 🐳 Docker - контейнеризация

- Что такое контейнеры и зачем они нужны
- Dockerfile - сборка своего образа
- docker-compose - окружение из нескольких сервисов
- Настройка связки: PHP-FPM + Artisan + Composer + Nginx + MySQL + Redis + Node(для VueJs)

**Практика:** упаковать один из своих Laravel-проектов/Vue-проектов в Docker, поднять локально одной командой `docker-compose up`.

---

<a id="section-6"></a>
## 6. 🔴 Redis - кэширование и очереди

- Что такое Redis и чем отличается от обычной БД
- Установка и подключение к Laravel
- Кэширование запросов и данных (`Cache::remember`)
- Хранение сессий в Redis
- Очереди задач (Queues) на Redis - рассылки, обработка файлов
- Rate Limiting (защита API от спама)

**Практика:** ускорить существующий проект, добавив кэширование тяжелых запросов через Redis.

<a id="section-7"></a>
## 7. 📝 WordPress - быстрые проекты для клиентов

Отдельный, но очень важный навык - **80% фриланс-заказов на "сделать сайт" - это WordPress**.

- Установка и администрирование WP
- Работа с популярными билдерами: **Elementor**, **WPBakery**
- Верстка кастомных тем (child theme, `functions.php`)
- Основы разработки плагинов
- WooCommerce - интернет-магазины на WP
- SEO-оптимизация (Yoast SEO, скорость загрузки)
- Безопасность и бэкапы (Wordfence, UpdraftPlus)
- Хостинг и деплой WP-сайтов (Timeweb, Beget, Hostinger и т.д.)

**Практика:** сделать 2-3 сайта под ключ - визитка, лендинг, интернет-магазин.

<a id="section-8"></a>
## 8. 🌐 Сайт-портфолио (обязательный пункт)

> ⚠️ Без портфолио на фрилансе очень сложно получить первые заказы. Клиенты хотят видеть примеры работ.

### Что должно быть на сайте-портфолио:

- Информация о себе, стек технологий, опыт
- Раздел с проектами: скриншоты + описание + **ссылка на живую версию** (demo)
- Ссылки на GitHub-репозитории проектов
- Контакты (Telegram, почта, соцсети)
- Резюме/CV в PDF (по желанию)

### 💡 Где хостить портфолио бесплатно

Если сайт-портфолио чисто фронтендовый (HTML/CSS/JS или Vue/React без бэкенда) - **лучший бесплатный вариант это [Vercel](https://vercel.com)**:

- Бесплатный деплой прямо из GitHub-репозитория
- Автоматический CI/CD - при пуше в `main` сайт обновляется сам
- Бесплатный SSL-сертификат и свой поддомен (`your-name.vercel.app`)
- Поддержка кастомного домена (можно подключить свой, если купите)
- Отлично работает с Vue/Vite, статикой и Jamstack-проектами

**Альтернативы для фронтенд-сайтов:**
- **Netlify** - аналогичен Vercel, тоже отличный вариант
- **GitHub Pages** — простой вариант для статики без сборки

> Для проектов с PHP/Laravel-бэкендом (демо интернет-магазинов и т.д.) Vercel не подойдёт — потребуется VPS-хостинг или что-то вроде связки Laravel Forge / Railway / связка с бесплатным VPS-тарифом на первое время.

**Практика:** задеплоить портфолио на Vercel через связку с GitHub — при каждом коммите сайт должен обновляться автоматически.

## 9. 💼 Погружение во фриланс и поиск клиентов

- Зарегистрироваться на биржах: **Kwork**, **FL.ru**, **Freelancer.com**

- Найти телеграмм чаты/каналы с большим трафиком (ссылка на такие чаты в тгк https://t.me/DevSpaceWork)
